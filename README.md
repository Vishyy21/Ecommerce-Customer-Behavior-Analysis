# E-Commerce Customer Behavior & Retention Analysis

## Tools Used
- Python
- SQL
- Power BI
- Pandas
- Matplotlib
- Seaborn

## Project Overview
This project analyzes customer purchasing behavior, retention trends,
membership performance, and satisfaction metrics for an e-commerce company.

## Key Features
- Customer segmentation
- Retention analysis
- Revenue analysis
- SQL business queries
- Interactive Power BI dashboard

## Dataset
E-commerce customer behavior dataset containing:
- Customer demographics
- Membership tiers
- Spending behavior
- Satisfaction metrics
- Purchase recency

## Project Structure
- data/ → raw & cleaned datasets
- python/ → analysis scripts
- sql/ → business SQL queries
- dashboard/ → Power BI dashboard
- screenshots/ → dashboard previews
